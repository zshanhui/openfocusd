OpenFocusd is still WIP, however the preview is ready to be tested here: <https://chromewebstore.google.com/detail/openfocusd/cimnmoclhghnbpamdblmakjfmbhmacpa>. Or you can build and load from source into your Chrome/Brave extensions.

The goal of OpenFocusd is to create a minimal, open, and privacy-first alternative to the popular StayFocusd Chrome extension which is owned by SensorTower, a marketing analytics corp.
